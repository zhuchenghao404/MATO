- **核心框架**：基于 Vue 3 (Composition API) 和 Vue Router 构建，采用 Pinia 风格的组合式 Store (`src/stores/auth.js`) 管理全局认证与用户状态。
- **功能模块**：
  - **学习系统**：通过 `marked` 渲染 Markdown 课程 (`src/content/learning`)，支持响应式目录导航与 AI 辅助解答 (`AiHelper.vue`, `AiBubble.vue`)。
  - **代码沙箱**：集成 CodeMirror 6 实现多语言（HTML/CSS/JS）在线编辑，利用 `iframe` 进行实时安全预览 (`views/admin/Pen.vue`)。
  - **用户中心**：处理登录注册、头像裁剪、经验值升级及签到逻辑。
- **工程化**：使用 Vite 作为构建工具，配置了针对后端 API (`/api`) 和资源 (`/uploads`) 的代理，并包含自定义插件以优化移动端 HMR 体验。
